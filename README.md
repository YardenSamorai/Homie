# Homie

ניהול הבית המשותף לזוג הורים: רשימת קניות, משימות ומסך "היום". האיפיון המלא: [`docs/SPEC.md`](docs/SPEC.md).

## פיתוח

```bash
npm install
npm run dev
```

האפליקציה רצה ב-http://localhost:3000 ומפנה ל-`/he` או `/en` לפי שפת הדפדפן.

## מבנה

- `src/app/[lang]` — כל הנתיבים, תחת קטע השפה (`he` / `en`).
- `src/app/[lang]/(app)` — המסכים שמאחורי השלד (סרגל לשוניות / סרגל צד).
- `src/i18n` — הגדרות שפה ומילונים.
- `src/components` — רכיבי השלד ורכיבי UI.
- `src/proxy.ts` — הפניה לנתיב השפה המועדף.
